# Stellar Burgers

Приложение для конструирования бургеров, разработанное на React + TypeScript с использованием Redux Toolkit. Пользователь может выбирать ингредиенты, собирать бургер, оформлять заказ и просматривать ленту заказов.

## Стек

- **React 18** — UI
- **TypeScript** — строгая типизация
- **Redux Toolkit** — глобальное состояние
- **React Router v6** — роутинг и модальные окна через URL
- **Webpack 5** — сборка
- **CSS Modules** — стилизация
- **clsx** — конкатенация CSS-классов

## Функциональность

- Конструктор бургера: выбор ингредиентов, счётчики, динамический подсчёт стоимости
- Оформление заказа с модальным окном подтверждения
- Лента заказов в реальном времени
- Регистрация, авторизация, восстановление пароля
- Личный кабинет: редактирование профиля, история заказов
- Защищённые маршруты для авторизованных пользователей
- Модальные окна управляются через URL (`/ingredients/:id`, `/feed/:id`, `/profile/orders/:id`)

## Структура проекта

```
src/
├── components/       # React-компоненты
├── pages/            # Страницы приложения
├── services/         # Redux store, слайсы, селекторы
├── utils/            # API, типы, константы
```

## Запуск

### 1. Клонирование

```bash
git clone https://github.com/MrMikhaiI/stellar-burgers.git
cd stellar-burgers
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

```bash
cp .env.example .env
```

### 4. Запуск в режиме разработки

```bash
npm run start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## Доступные команды

| Команда | Описание |
|---|---|
| `npm run start` | Запуск дев-сервера |
| `npm run lint` | Проверка кода ESLint |
| `npm run lint:fix` | Автоисправление ESLint |
| `npm run format` | Форматирование кода Prettier |
| `npm run storybook` | Запуск Storybook |

## Маршруты

| Маршрут | Описание | Доступ |
|---|---|---|
| `/` | Конструктор бургера | Все |
| `/feed` | Лента заказов | Все |
| `/login` | Вход | Только гость |
| `/register` | Регистрация | Только гость |
| `/forgot-password` | Восстановление пароля | Только гость |
| `/profile` | Личные данные | Только авторизован |
| `/profile/orders` | История заказов | Только авторизован |
